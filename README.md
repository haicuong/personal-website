# Nguyen Hai Cuong's Digital Garden & Portfolio

Showcase my software engineering projects, technical notes and controversial psychology through opposing lenses.

## 🛠 Tech Stack

- **Build Tool:** Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS + `@tailwindcss/typography`
- **Hosting:** GitHub Pages / Vercel

## 📁 Project Structure

- `index.html` — Home / Landing page
- `blog/` — Blog index and published notes
- `projects/` — Portfolio showcase
- `src/` — Custom TypeScript logic, styles, and raw Markdown content

## 🚀 Local Setup & Development

1. **Clone the repository:**

   ```bash
   git clone https://github.com/haicuong/personal-website.git
   cd personal-website
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Start local development server:**

   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
